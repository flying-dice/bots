# Visual references & Avatars

Team profile avatars generated with a unified 3D stylized mecha visual style:
centered 1:1 bust portraits on a dark charcoal slate background with subtle hexagonal grid,
authentic mechanical construction, and luminous optics (cyan-blue for Autobots, ruby-red for Decepticons).
